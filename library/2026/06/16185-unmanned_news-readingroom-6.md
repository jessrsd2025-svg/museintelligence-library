#### 3. Ingestion & canonicalization pipeline (stepwise)


1. **Source capture** — telemetry, AIS, port manifests, HUMINT, uploaded docs.
2. **Normalization** — reproject to common CRS; raster/vector cleaning via GDAL/Rasterio; extract routes with OSMnx.
3. **Polygon canonicalization** — produce RFC‑8785 canonical GeoJSON for each observed polygon (vessel polygon, port AOI).
4. **Hashing & anchoring** — compute SHA‑256 over canonical bytes; store digest + metadata (timestamp, source, chain‑of‑custody) in the American Science Cloud registry.
5. **Graph ingestion** — create Neo4j nodes: *Event*, *Polygon*, *Actor*, *Asset*, *ProvenanceHash*; link via edges to form QGA proof trees.
6. **Analytics** — run PySAL spatial clustering and NetworkX propagation to compute threat clusters and contagion paths.
7. **Output** — signed GeoJSON layers, Neo4j query views, risk heatmaps, and an auditable proof tree for each anchored event.

#### 5. Cryptographic anchoring & QGA proof‑tree pattern


- **Atomic unit:** RFC‑8785 canonical GeoJSON polygon + metadata JSON.
- **Digest:** `sha256(canonical_geojson_bytes)` → store digest in registry with timestamp and signer.
- **Proof‑tree nodes:**

  - *Canonicalization* → digest node
  - *Verification* (cross‑source corroboration) → signed attestations
  - *Policy action* → enforcement record (linked to digest + attestations)
- **Neo4j model:** nodes = {Observation, PolygonDigest, Source, Attestation, Action}; edges = {observed_in, canonicalized_to, attested_by, acted_on}. This yields a queryable QGA proof tree for audit and legal use.
