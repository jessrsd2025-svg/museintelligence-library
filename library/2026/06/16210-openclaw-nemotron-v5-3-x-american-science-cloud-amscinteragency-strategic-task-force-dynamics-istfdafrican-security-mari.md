## PYTHON CANONICALIZATION PIPELINE


```
import hashlibimport rfc8785def canonical_digest(feature):    canonical_json = rfc8785.dumps(feature)    digest = hashlib.sha256(        canonical_json.encode("utf-8")    ).hexdigest()    return {        "canonical_json": canonical_json,        "sha256": digest    }
```
