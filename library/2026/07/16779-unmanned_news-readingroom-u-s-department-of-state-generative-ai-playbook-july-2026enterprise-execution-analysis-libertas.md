1. **StateChat & FAMsearch:** Evolved from a tabbed lookup tool into a background **agentic retrieval service**. When a diplomat drafts official communications (cables), background agents automatically query the Foreign Affairs Manual (FAM) and Foreign Affairs Handbook (FAH) to surface compliance rules and cited precedents invisibly.
2. **Proving Ground:** A free-tier enterprise workspace enabling non-engineering staff (“citizen developers”) to build specialized chatbots, workflow automations, and data visualizations using production-grade AI assets under unified security guardrails. Over **120 builder projects** have been deployed.
3. **Funhouse:** A secure data science sandbox built on Azure Databricks inside `Data.State`, allowing advanced ML experimentation and data visualization on diplomatic datasets at low aggregate cost.
4. **Prompter API:** A standardized, pre-approved API gateway allowing any internal Department application to call underlying LLM infrastructure for document drafting, translation, summarization, and code assistance without separate governance reviews.
5. **Northstar & SMART AI:** Enterprise intelligence feeds processing 100,000+ global media sources in 100+ languages and analyzing official cable archives for decision support.

  - *Researching Information & Summarizing Documents:* 40–50% selection, **1.65–1.72 hrs/wk saved**.
- **High Selection / Low Savings (Broad Reach):**
  - *Drafting Emails / Communications:* 51% selection, **1.45 hrs/wk saved** (>10,000 cumulative hours/week across workforce).

### 1. LIBERTAS (Workflow Autonomy & Agentic Orchestration)


- **Playbook Concept:** Transitioning from passive chatbots to background agent orchestration (e.g., FAMsearch calling cables, policy pre-mortems).
- **LIBERTAS Alignment:** Maps to the non-linear **Observe-Orient-Decide-Act-Feedback** loop. Agents run background GraphRAG queries across spatial polygons and institutional memory without breaking user workflow.


### 2. VERITAS (Epistemic Provenance & Privacy Integrity)


- **Playbook Concept:** ITEVV testing under NIST AI RMF (EO 13960); privacy-first prompt telemetry via CLIO; strict citation requirements for official policy.
- **LIBERTAS Alignment:** Enforces cryptographic anchoring (SHA-256) and explicit epistemic status tagging (`SOURCE_ASSERTION` vs. `MODEL_SCORE`). Model scores are isolated from raw evidence.


### 3. AEQUITAS (Interdiction Gates & FISMA High Compliance)


- **Playbook Concept:** Securing a FISMA High ATO to allow SBU data processing; establishing clear boundaries on what AI is “allowed” to execute.
- **LIBERTAS Alignment:** Integrates directly with the **Silent-Upgrade Interdiction Gate**. The system intercepts unverified causal or control propositions ($\mathtt{CONTROLS}$, $\mathtt{FINANCES}$, $\mathtt{DIRECTS}$) generated during prose analysis, quarantining them in `proposed_relationships` until human analyst review.
