Every analytical object records:


- Observation ID
- Timestamp
- Data source
- Canonical JSON hash
- Digital signature
- Review status
- Confidence estimate
- Supporting references
- Graph node identifier
- Transformation history
- Analyst notes
- Publication state


This enables analysts to trace conclusions back to underlying observations and review history.


```
Conclusion    ↓Assessment    ↓Evidence    ↓Feature    ↓Observation    ↓Source
```


The provenance fabric is the backbone of legitimacy.

# XIX. Architectural Principles


The extended LIBERTAS specification is centered on five principles.


## 1. Evidence before assertion


Treat observations as claims until they are reviewed and supported.


## 2. Provenance by design


Preserve lineage, timestamps, transformations, and review state throughout the pipeline.


## 3. Hybrid reasoning


Combine vector retrieval with explicit graph relationships for transparent analysis.


## 4. Human-centered review


Keep analysts in the loop for interpretation, validation, and publication.


## 5. Layered visualization


Present policy, infrastructure, spatial, temporal, and knowledge layers as complementary views rather than a single authoritative picture.
