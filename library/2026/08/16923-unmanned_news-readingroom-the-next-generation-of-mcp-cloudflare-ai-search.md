## Give your agents a search engine for your data


C2 command-line tool and Python library to convert arXiv papers to Markdown format


You can automate the process of creating markdown files from arXiv papers using Python. Below is a comprehensive approach leveraging **arXiv API**, data filtering, and markdown generation.


## Steps: Markdown is the Code


1. **Fetch Papers from arXiv:** Use the arXiv API to get metadata such as title, authors, abstract, and links.
2. **Filter or Categorize Papers:** Decide which papers belong in `quarantine.md` versus `Llama rejection.md` based on themes, keywords, or relevance.
3. **Generate Markdown Files:** Format each paper’s data neatly in markdown so it can be read easily.


## Sample Python Script


```python
# Language: Pythonimport requestsimport xml.etree.ElementTree as ET# Function to fetch papers from arXivdef fetch_arxiv_papers(query, max_results=5):    url = f"http://export.arxiv.org/api/query?search_query=all:{query}&start=0&max_results={max_results}"    response = requests.get(url)    root = ET.fromstring(response.content)        papers = []    for entry in root.findall('{http://www.w3.org/2005/Atom}entry'):        title = entry.find('{http://www.w3.org/2005/Atom}title').text.strip()        summary = entry.find('{http://www.w3.org/2005/Atom}summary').text.strip()        authors = [author.find('{http://www.w3.org/2005/Atom}name').text for author in entry.findall('{http://www.w3.org/2005/Atom}author')]        link = entry.find('{http://www.w3.org/2005/Atom}id').text        papers.append({"title": title, "authors": authors, "summary": summary, "link": link})    return papers# Function to write to a markdown filedef write_markdown(filename, papers):    with open(filename, 'w', encoding='utf-8') as f:        f.write(f"# {filename.replace('.md','').title()}")        for paper in papers:            f.write(f"## [{paper['title']}]({paper['link']})")            f.write(f"**Authors:** {', '.join(paper['authors'])}")            f.write(f"**Abstract:**{paper['summary']}")            f.write("---")# Example usageif __name__ == "__main__":    quarantine_papers = fetch_arxiv_papers("quarantine")  # Customize query    llama_rejection_papers = fetch_arxiv_papers("LLaMA rejection")  # Customize query        write_markdown("quarantine.md", quarantine_papers)    write_markdown("Llama_rejection.md", llama_rejection_papers)
```


## Notes:


- **Dependency:** Install `requests` library with `pip install requests`.
- You can **customize the query terms** to better filter papers relevant to quarantine-related research or LLaMA model rejection.
- The generated markdown file includes:
  - Paper title as a clickable link
  - Authors
  - Abstract
  - Separator line for readability
- This script can be extended to fetch **PDF links**, include **published dates**, or **add categories** for more structured notes.


## Summary


This method automates extracting scientific paper details from arXiv and produces clean, readable markdown files. You can refine it further by integrating **keyword filtering**, **automatic summaries**, or advanced parsing for larger datasets.

At Startup School 2026, YC President & CEO Garry Tan explains why we’re entering the era of personal AGI: AI agents that run on your own infrastructure, compound your knowledge over time, and dramatically increase your ability to build. He shares the tools and workflows he uses every day, why every founder should own their intelligence instead of renting it, and what it means to build under your own power.
