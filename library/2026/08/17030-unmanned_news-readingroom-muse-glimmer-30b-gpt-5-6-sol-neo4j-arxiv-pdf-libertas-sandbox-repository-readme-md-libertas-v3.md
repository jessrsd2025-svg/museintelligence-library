## 3. Key Architectural Choices Exploded


- **Why Markdown?** Standard PDF readers flatten document hierarchies. Parsing via layout-aware converters like `marker` preserves structural tables, mathematical syntax (`LaTeX`), headers (`#`, `##`), and bold terminology so chunks retain formatting integrity during tokenization.
- **FAISS Similarity Search:** Utilizes memory-safe native vector operations, establishing flat indexing matching L2 distance metrics for high-speed local similarity lookups.
- **llama-cpp-python:** Interfaces with ArXiv corpora locally using GGUF quantization, allowing high-performance execution on standard hardware without exposing data to external cloud APIs.
