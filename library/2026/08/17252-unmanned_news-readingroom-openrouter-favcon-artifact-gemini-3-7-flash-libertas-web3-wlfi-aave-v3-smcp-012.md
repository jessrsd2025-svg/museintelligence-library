### 1. Epistemic Status Taxonomy for DeFi Infrastructure


1. **Threat Intelligence (`SOURCE_ASSERTION` / `UNVERIFIED`):**
  - **Source Material:** Security researcher blog posts, unverified Discord rumors, zero-day disclosure claims regarding WLFI proxy implementations or Aave v3 pool configuration parameters.
  - **Handling Protocol:** Quarantined in `corridor_claims` as `ALLEGED_BY_SOURCE`. Strictly prohibited from triggering automated pause triggers or protocol interdiction scripts.
2. **Market & Sentiment Signals (`PROBABILISTIC_SIGNAL` / `SENTIMENT_ONLY`):**
  - **Source Material:** Liquidity shifts in WLFI/AAVE DEX pools, Polymarket contract probability spikes regarding protocol exploits or governance approvals.
  - **Handling Protocol:** Processed with `source_use_tag = SENTIMENT_ONLY`. Used exclusively for orientation overlays in the GraphRAG context engine.
3. **Verified Compromise (`VERIFIED_FACT` / `EXECUTION_PROOF`):**
  - **Source Material:** Deterministic RPC block telemetry, state differential proofs, failed invariant checks in formal verification harnesses.
