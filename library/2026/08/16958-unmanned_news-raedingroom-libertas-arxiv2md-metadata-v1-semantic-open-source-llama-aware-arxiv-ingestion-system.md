AI Overview


An end-to-end Retrieval-Augmented Generation (RAG) pipeline can successfully ingest PDF papers from arXiv, convert them into clean Markdown, index them into a vector database, and query them using a local LLaMA model. [[1](https://github.com/topics/scientific-literature)]


Core Architecture


```
[arXiv PDF] ➔ [Marker / Nougat] ➔ [Markdown Text] ➔ [Recursive Splitter] ➔ [ChromaDB] ➔ [LLaMA 3] ➔ [Answer]
```


Complete Implementation


Here is the complete Python code using `langchain`, `chromadb`, and `marker-pdf` (a high-speed tool for converting PDFs to clean Markdown, handling math and tables). [[1](https://www.youtube.com/watch?v=LK-OyelN9MU), [2](https://medium.com/@arunpatidar26/rag-chromadb-ollama-python-guide-for-beginners-30857499d0a0)]

```
import osimport requestsfrom marker.convert import convert_single_pdffrom marker.models import load_all_modelsfrom langchain_text_splitters import RecursiveCharacterTextSplitterfrom langchain_community.vectorstores import Chromafrom langchain_community.embeddings import HuggingFaceEmbeddingsfrom langchain_community.llms import Ollamafrom langchain_core.prompts import ChatPromptTemplatefrom langchain_core.runnables import RunnablePassthroughfrom langchain_core.output_parsers import StrOutputParser# ==========================================# 1. DOWNLOAD & CONVERT ARXIV TO MARKDOWN# ==========================================def download_arxiv_pdf(arxiv_id: str, output_path: str = "paper.pdf"):    """Downloads a PDF from arXiv given its ID."""    url = f"https://arxiv.org{arxiv_id}.pdf"    response = requests.get(url)    if response.status_code == 200:        with open(output_path, "wb") as f:            f.write(response.content)        return output_path    raise Exception(f"Failed to download paper {arxiv_id}")def pdf_to_markdown(pdf_path: str) -> str:    """Converts PDF to high-quality Markdown using Marker."""    # Load model weights for layout, OCR, and text ordering    model_lst = load_all_models()    full_text, _, _ = convert_single_pdf(pdf_path, model_lst)    return full_text# ==========================================# 2. INITIALIZE RAG COMPONENTS# ==========================================# Download a sample paper (e.g., LLaMA 3 technical report or similar)pdf_file = download_arxiv_pdf("2407.21783") markdown_content = pdf_to_markdown(pdf_file)# Split Markdown while preserving structure (headers, lists)text_splitter = RecursiveCharacterTextSplitter(    chunk_size=1000,    chunk_overlap=200,    separators=["\n## ", "\n### ", "\n\n", "\n", " "])chunks = text_splitter.create_documents([markdown_content])# Embed chunks and store in a local vector databaseembeddings = HuggingFaceEmbeddings(model_name="BAAI/bge-small-en-v1.5")vector_store = Chroma.from_documents(chunks, embeddings, embedding_idx="arxiv_db")retriever = vector_store.as_retriever(search_kwargs={"k": 3})# ==========================================# 3. LLaMA GENERATION PIPELINE# ==========================================# Assumes Ollama is running locally with llama3 loadedllm = Ollama(model="llama3")prompt_template = """You are an expert research assistant. Answer the question based strictly on the provided context from the arXiv paper. If you do not know the answer, say that you do not know.Context:{context}Question: {question}Answer:"""prompt = ChatPromptTemplate.from_template(prompt_template)def format_docs(docs):    return "\n\n".join(doc.page_content for doc in docs)# Create the end-to-end chainrag_chain = (    {"context": retriever | format_docs, "question": RunnablePassthrough()}    | prompt    | llm    | StrOutputParser())# ==========================================# 4. EXECUTION# ==========================================if __name__ == "__main__":    query = "What are the main architectural optimizations introduced in this paper?"    response = rag_chain.invoke(query)    print(response)
```

Key Technical Considerations


- **PDF Parsing Quality:** Standard parsers (like PyPDF) ruin mathematical equations and table formats. Using Markdown-specific tools like `marker-pdf` or `facebook/nougat` preserves LaTeX syntaxes (`$e=mc^2$`), which LLaMA models natively understand.
- **Markdown Splitting:** Using a `RecursiveCharacterTextSplitter` with explicit Markdown headers (`\n##` ) prevents sections from getting cut mid-sentence, preserving semantic context.
- **Local LLM Deployment:** This pipeline utilizes `Ollama` for zero-cost, private inference. Ensure Ollama is installed and running (`ollama run llama3`) before launching the script. [[1](https://dl.acm.org/doi/10.1145/3769696.3771214), [2](https://www.tigerdata.com/blog/use-open-source-llms-in-postgresql-with-ollama-and-pgai), [3](https://javapro.io/2026/06/03/the-gen-ai-iceberg-java-tooling-edition/)]
