## Abstract


According to the Libertas Unified Intelligence Lattice (v6.10), the Islamic Revolutionary Guard Corps (IRGC) operates as a vertically integrated intelligence-operations organism. Rather than trying to map its influence using static, fixed geographic borders, its global activities are more accurately analyzed as corridors, resource flows, and complex network relationships.


The primary strategic implications derived from this structural model include:
- **Corridor-Based Logistical Controls.** The IRGC controls half of Iran’s total oil exports. This economic leverage funds global corridors that blend commercial maritime trade with gray-zone paramilitary actions.
- **Network-Driven Infrastructure Overlays.** By mapping influence as active nodes and network flows rather than sovereign territory, the system identifies hidden touchpoints where state-backed funds interact with global decentralized financial infrastructures.
- **Asymmetric Maritime Interdiction Risks.** The IRGC’s structural presence along primary maritime channels means that localized municipal laws (such as the Iranian Marine Act of 1993) directly alter the risk profile of international shipping lanes.


This paper presents the AEQUITAS Rulechain Interdiction Gate and the ARXIV-MD-INGEST-V1 ingestion architecture that enforce those distinctions: an air-gapped, local-inference pipeline in which source material is fingerprinted, classified, and registered in a Source / Metadata / Context / Provenance (SMCP) graph, and in which no claim is promoted to a verified fact, no causal edge is created, and no graph mutation occurs without human review.

## 3. arXiv Acquisition Layer


### Acquisition contract


The acquisition component retrieves only bibliographic metadata and source references required for ingestion.

### `arxiv_ingest.py`


The following code is reproduced from the source document. Line breaks and indentation follow the PDF’s rendering of the file.


```
`"""
arxiv_ingest.py
ARXIV-MD-INGEST-V1
External acquisition boundary.
IMPORTANT:
This process is NOT the air-gapped inference environment.
Run it on an approved acquisition workstation or transfer
the resulting immutable acquisition bundle into the enclave.
"""

from __future__ import annotations

import hashlib
import json
import time
import urllib.parse
import urllib.request
import xml.etree.ElementTree as ET
from pathlib import Path

ARXIV_API = "https://export.arxiv.org/api/query"

SEARCH_TERMS = [
    "maritime security",
    "maritime knowledge graph",
    "GraphRAG",
    "oil supply chain",
    "chokepoint resilience",
    "Iran maritime",
    "Hugging Face",
    "large language model",
]

def sha256_bytes(data: bytes) -&gt; str:
    return hashlib.sha256(data).hexdigest()

def fetch_arxiv(query: str, start: int = 0, max_results: int = 25) -&gt; bytes:
    params = urllib.parse.urlencode({
        "search_query": f"all:{query}",
        "start": start,
        "max_results": max_results,
    })
    url = f"{ARXIV_API}?{params}"
    request = urllib.request.Request(
        url,
        headers={
            "User-Agent": "Unmanned_News-ReadingRoom/ARXIV-MD-INGEST-V1"
        },
    )
    with urllib.request.urlopen(request, timeout=30) as response:
        return response.read()

def parse_feed(xml_bytes: bytes) -&gt; list[dict]:
    root = ET.fromstring(xml_bytes)
    ns = {
        "atom": "http://www.w3.org/2005/Atom"
    }
    records = []
    for entry in root.findall("atom:entry", ns):
        title = entry.findtext("atom:title", "", ns).strip()
        summary = entry.findtext("atom:summary", "", ns).strip()
        published = entry.findtext("atom:published", "", ns).strip()
        updated = entry.findtext("atom:updated", "", ns).strip()
        identifier = entry.findtext("atom:id", "", ns).strip()
        authors = [
            a.findtext("atom:name", "", ns).strip()
            for a in entry.findall("atom:author", ns)
        ]
        categories = [
            c.attrib.get("term", "")
            for c in entry.findall("atom:category", ns)
        ]
        records.append({
            "source_id": identifier.rsplit("/", 1)[-1],
            "source_type": "ARXIV",
            "title": title,
            "authors": authors,
            "abstract": summary,
            "published": published,
            "updated": updated,
            "categories": categories,
            "source_url": identifier,
            "epistemic_status": "SOURCE_METADATA",
            "provenance_status": "PENDING_REVIEW",
        })
    return records

def write_acquisition_bundle(records: list[dict], output: Path) -&gt; None:
    payload = json.dumps(
        records,
        ensure_ascii=False,
        sort_keys=True,
        indent=2,
    ).encode("utf-8")
    digest = sha256_bytes(payload)
    envelope = {
        "contract": "ARXIV-MD-INGEST-V1",
        "schema": "libertas.arxiv-acquisition.v1",
        "record_count": len(records),
        "sha256": digest,
        "records": records,
    }
    output.write_text(
        json.dumps(
            envelope,
            ensure_ascii=False,
            sort_keys=True,
            indent=2,
        ),
        encoding="utf-8",
    )

if __name__ == "__main__":
    all_records = []
    for term in SEARCH_TERMS:
        raw = fetch_arxiv(term)
        all_records.extend(parse_feed(raw))
        time.sleep(3)
    # Deterministic de-duplication.
    unique = {
        r["source_id"]: r
        for r in all_records
    }
    write_acquisition_bundle(
        list(unique.values()),
        Path("arxiv_acquisition_bundle.json"),
    )
`
```

## 6. quarantine.md


A paper enters `quarantine.md` when it requires additional provenance review or contains contextual claims that must not be silently promoted.


### LIBERTAS Quarantine Register


**Purpose.** This file contains source records isolated from automatic epistemic promotion.


**Mandatory controls:**
- `human_review_required: true`
- `graph_mutation_authorized: false`
- `causal_inference_authorized: false`
- `semantic_similarity_is_evidence: false`
- `prediction_signal_is_event: false`


**Quarantine entry:**
- **Source:** `SRC-ARXIV-`
- **Disposition:** `QUARANTINED`
- **Reason:** Contextual or insufficiently adjudicated material requires human review.


**Allowed:** metadata preservation; text normalization; hashing; embedding for retrieval; local semantic search; provenance registration.


**Prohibited:** automatic factual promotion; causal edge creation; attribution; operational targeting; C2 inference; autonomous graph mutation.
