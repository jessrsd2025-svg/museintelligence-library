Below is a complete **Streamlit dashboard mockup** that visualizes the Ebola outbreak in Sierra Leone (2014-2016) and the 1854 Cholera outbreak in London side-by-side. This builds on the GeoJSON overlays and semantic retrieval flows from our previous discussions. The dashboard uses:


- **Folium** for interactive maps (embedded in Streamlit via `streamlit_folium`).
- **LangChain RetrievalQA** for semantic Q&A on both outbreaks (ingesting metadata from GeoJSON and PDFs like the Chatham House report).
- **LangSmith-style tracing** for provenance/compliance (simple logging with timestamps, trace IDs, and hashes; can be extended to full LangSmith).
- **Side-by-Side Layout**: Two maps for direct comparison, with clickable features, heatmaps, and Q&A popups.
- **Traceable Nodes**: Each map feature (e.g., polygon/point) triggers a traceable Q&A query, logging retrieval details.
- **Escalation Hooks**: If a query flags high risk (e.g., risk_score > 0.9), it simulates an alert (console log; extend to Slack/Signal).


This is a self-contained Python script. Save it as `outbreak_dashboard.py` and run with `streamlit run outbreak_dashboard.py`. Install dependencies: `pip install streamlit streamlit-folium langchain langchain_openai chromadb geojson folium pandas`.


### Dashboard Features


- **Side-by-Side Maps**: Left: Ebola (Sierra Leone) with polygons colored by risk_score (red for high-risk). Right: Cholera (London) with points/polygons for deaths/pump.
- **Interactivity**: Click a feature to trigger a Q&A query (e.g., “What interventions were used here?”). Results show with trace logs.
- **Q&A Section**: Text input for custom queries across both datasets.
- **Trace Logs**: Displayed below queries, with provenance (source, timestamp, hash).
- **Heatmap Overlays**: Visualizes case density.
- **Compliance**: Logs are exportable (simulated CSV download).

## 🧠 Q&A: Semantic Comparison


| Question | Ebola Outbreak: Sierra Leone (GeoJSON/Modern GIS) | Cholera Outbreak: London 1854 (John Snow’s Map) |
| --- | --- | --- |
| **What was the mapping method?** | GeoJSON polygons over 1,300+ administrative zones with outbreak metadata | Hand-drawn spatial points for deaths and pump locations |
| **How were cases spatialized?** | Semantic retrieval using LangChain—embedding response challenges, agency roles, transmission vectors | Manual clustering of deaths around Broad Street pump |
| **Geospatial tooling?** | Folium, Leaflet.js, LangChain RetrievalQA, LangSmith tracing, VHF database | Static paper map, later digitized in ArcGIS tutorials |
| **Q&A capabilities?** | AI-driven queries like: “What peak transmission zones exist in Kenema?” → traced answer with source docs and vector ID | “Where did cholera deaths concentrate?” → static visual cluster |
| **Response coordination?** | DERC/CCC zones tagged with metadata (e.g. NERC events, lead agency) and semantic tags like “mass_burials”, “delayed isolation” | Snow’s findings led to pump handle removal, a form of rapid response |
| **Audit and provenance features?** | Every semantic answer logged via LangSmith with `trace_id`, retrieval method, and metadata | Historical provenance inferred post-analysis; no real-time logging |

## 🔎 Geospatial Intelligence Lessons


- **From Snow to Sierra Leone**: What Snow did manually with mapping death patterns, modern agents now automate using LangChain ingestion, spatial vector metadata, and GeoJSON dashboards.
- **Auditability Leap**: Ebola Q&A answers now include semantic trace logs (`trace_id: kenema_2024_vector`), source PDFs (e.g. “MSF Kenema Report”), and retrieval path transparency—versus the inference-only workflows of 1854.
- **Operational Fusion**: LangChain RetrievalQA empowers field teams to ask “What zones had the worst hospital amplification?” and get answers linked to outbreak polygons, critical events, and intervention history.
