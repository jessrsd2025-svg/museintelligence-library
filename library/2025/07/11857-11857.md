### How to Use This Schema


- **Ingestion Pipeline:** Each city/county row is a GeoJSON-ready “node” for overlay, search, and dashboard display, with reform lag computed and ready for dynamic color/timeline display.
- **Data Drilldown:** You can use CDC SUDORS, state [California](https://skylab.cdph.ca.gov/ODdash/), [New Jersey](https://bloustein.rutgers.edu/new-jersey-state-policy-lab-mapping-new-jerseys-overdose-hotspots-insights-from-state-administrative-data/), or NEMSIS for full jurisdiction/year-level trend and crosswalk.
- **RAG/LLM Use:** Chunk at city, overlay, or event level; treat lag, trust, or incident metrics as subnodes for fact-explainable Q&A, or dashboard triggers.
- **Visualization Hints:** Display “reform lag bar” alongside incident heatmap; link overlays to CDC/NEMSIS dashboards for live drill-down.
