# 2. Authentication/Authorization Middleware Example (Python/FastAPI)


Here’s a simple JWT header auth middleware for FastAPI:


```
from fastapi import FastAPI, HTTPException, Depends, Request
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
import jwt

app = FastAPI()
bearer = HTTPBearer()
SECRET = "replace-with-very-long-random-secret"

def verify_token(credentials: HTTPAuthorizationCredentials = Depends(bearer)):
    try:
        payload = jwt.decode(credentials.credentials, SECRET, algorithms=["HS256"])
        return payload
    except Exception:
        raise HTTPException(status_code=403, detail="Invalid credentials")

@app.get("/secure-endpoint")
def secure_route(user=Depends(verify_token)):
    return {"message": "Authenticated!", "user": user}
```
